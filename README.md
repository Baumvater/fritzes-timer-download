# Fritzes Timer – Download

Trainings-Timer fürs Modellfliegen (Android).

**Download der aktuellen Version:**
https://github.com/Baumvater/fritzes-timer-download/releases/latest/download/fritzes-timer.apk

APK auf dem Handy öffnen und installieren („Installation aus unbekannten
Quellen“ einmalig erlauben).

## Bedienung

- **Leiseknopf:** Rahmenzeit starten
- **„Start“:** Flugzeit starten
- **„Stopp“:** Flugzeit speichern
- **„Neustart“:** Flugzeit neu starten

Die App muss offen sein, der Bildschirm bleibt an.
